# Contributing

Issues and pull requests are welcome for corrections to topologies, simulation
setups, lookup tables or documentation.

Report problems through the issue form. Include the affected file path, the
GROMACS version used, the exact command or `grompp` message and what you
expected.

Keep pull requests focused. When updating force-field or topology files,
explain the change and include validation details or a minimal test run. Do
not commit large binary trajectories.
